# Mini Core de Logística - Cálculo de Costos de Envíos

Aplicación funcional desarrollada bajo el patrón de arquitectura **MVC (Modelo-Vista-Controlador)**. Resuelve el problema de cálculo de costos de envíos por repartidor dentro de un rango de fechas aplicando tarifas por kilogramo según la zona de entrega.

## 🛠️ Tecnologías y Arquitectura Utilizada
* **Lenguaje:** PHP 8.x
* **Framework / Patrón:** Arquitectura limpia MVC (Model-View-Controller) inspirada en CakePHP.
* **Base de Datos:** MySQL / MariaDB (Conexión mediante PDO segura).

## 🚀 Instrucciones para Ejecución Local
1. Clonar este repositorio dentro de la carpeta `htdocs` de XAMPP.
2. Importar el script SQL incluido en la base de datos de MySQL.
3. Configurar las credenciales de tu base de datos en `config/conexion.php`.
4. Abrir el navegador e ingresar a: `http://localhost/MiniCore/`
